# Aureon AI Lab — Kit de replicación (50 €)

## Cambios de esta versión
- El botón de Aureon Web Kits usa el enlace de pago de Revolut facilitado por el propietario.
- Se muestra el precio de 50 €.
- Se explica que la entrega del paquete digital es manual tras verificar el pago.
- Se añade un acceso de contacto para gestionar la entrega.
- Se aclara que las skills de terceros conservan sus licencias y autorías originales.

## Límite operativo importante
El payment link de Revolut, usado de esta forma, no notifica a esta web de forma autenticada ni desbloquea contenido automáticamente. Verificar el pago en Revolut y enviar el kit manualmente. Para automatizar el acceso se requiere una integración de Merchant API y webhook, con credenciales privadas en el servidor.
