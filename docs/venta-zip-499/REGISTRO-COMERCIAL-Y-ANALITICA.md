# Registro comercial y analítica de Aureon

La página AI Lab emite eventos de interfaz (`view_item_list` y `begin_checkout_click`) a un evento personalizado `aureon:analytics` y, si existen, a `dataLayer` o `gtag`. No registra por sí sola ventas confirmadas ni datos personales, y no crea un panel de métricas persistente.

Para medir ventas reales, configurar una herramienta de analítica respetando el consentimiento y la política de cookies. La venta mediante Revolut de este paquete se verifica manualmente; registrar la venta solo después de confirmar el pago. No inferir compras a partir de clics.

Las opiniones de clientes deben ser reales, autorizadas y atribuibles a una compra verificada. Mientras no haya reseñas reales, la página muestra un aviso transparente de que estarán disponibles próximamente; no publica testimonios ficticios ni puntuaciones falsas.
