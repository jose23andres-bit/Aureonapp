# Aureon AI Replication Kit

Kit de referencia para replicar una sección de catálogo de habilidades de IA, con estética oscura premium, búsqueda, filtros, enlaces a fuentes y comandos copiables. No es un producto oficial de Vercel ni incluye soporte oficial de Vercel.

## Contenido
- `src/components/ai-lab.tsx`: componente React de la sección AI Lab.
- `src/ai-lab.css`: estilos de AI Lab extraídos del proyecto Aureon.
- `docs/INSTALACION.md`: guía de integración.
- `docs/LICENCIAS-Y-ALCANCE.md`: alcance y notas de licencias.

## Requisitos
- React compatible con hooks.
- `lucide-react` para iconos.
- Un proyecto web con CSS global y una forma de registrar la ruta `/ai-lab`.

## Aviso de entrega y pago
Este kit se entrega manualmente por Aureon tras verificar el pago en Revolut. El enlace de pago no concede acceso automático. El precio indicado en la página de venta es 50 €.
