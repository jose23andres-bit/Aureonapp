# AUREON AI PROJECT · landing

Landing estática (HTML, CSS y JS, sin dependencias) en negro y dorado, con barra inferior tipo app en móvil.

- `index.html`: contenido y secciones
- `styles.css`: estilos
- `app.js`: cabecera, aparición suave y barra inferior
- `img/`: imágenes de la web actual

Para verla en local: `python3 -m http.server 8000` y abrir http://localhost:8000

Las tarjetas enlazan a las páginas de https://aureonaiproject.netlify.app/
